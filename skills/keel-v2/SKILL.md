# Keel v2 — the full rules (Tier 2: loaded on demand)

The project's `CLAUDE.md` carries only Keel's Tier-1 router: the lane rule, the
surface names, the rigor lines, the invariant names and an authorities index.
Everything that defines them lives in the two files next to this skill. Read
the one the task needs, in full; they are the rules verbatim, not a summary:

- **`LAWS.md`** (this skill's directory) — the eleven danger surfaces with
  their definitions, the invariants with the two layers each one names, and the
  /review tripwires. Read it before a HEAVY call, a HEAVY plan, and every review.
- **`CLAUDE.md`** (this skill's directory) — the full router: §0 lanes and the
  pre-declaration rule, §1 FAST lane, §2 HEAVY lane, §3 one-shot authorization,
  §4 context economy and the memory protocol, §5 priority over other skills,
  §6 lanes, graphify-first comprehension and trade-off honesty. Where it says
  LAWS is "appended below this router", read `LAWS.md` beside it instead.

Precedence is unchanged: these rules outrank other skills; the project's
*Standing authorization* block decides how FAST and HEAVY work end; a Keel gate
(hook, deny rule, CODEOWNERS, ruleset) that blocks an action wins, and you take
the path its message names.
